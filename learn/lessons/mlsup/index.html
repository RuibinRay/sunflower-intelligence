Four models can answer the same yes-or-no question. The fair way to pick one is to score each only on rows it never trained on, and to know what each model is doing.

The idea

Judge a model only on data it didn’t learn from. In k-fold cross-validation the rows are dealt into k folds; each fold is held out once while the others train the model, so every row is predicted exactly once, by a model that never saw it. Score with AUC, the chance a random “yes” scores above a random “no” (0.5 is a coin flip), which accuracy can’t match when one class is rare.

A decision tree asks one question at a time, choosing the split that leaves the two sides purest. Grown deep, it memorises noise: a big gap between training and held-out scores is overfitting. A random forest grows many deep trees, each on a bootstrap sample and shown a random few columns at each split, then averages them. k-nearest neighbours predicts from the most similar rows, so columns must be standardised first.

Permutation importance shuffles one column among the held-out rows and measures how far AUC falls. It shows what the model uses, not what matters in the world: two correlated columns share the credit.

The formula

G = 1 − Σk pk2, ΔG = Gparent − nLnGL − nRnGR, Var(forest) = ρσ2 + (1 − ρ)σ2B

G
Gini impurity of a node: 0 when every row is the same class, 0.5 at most for two classes
pk
share of the node’s rows in class k
ΔG
how much a split lowers impurity; the tree takes the split with the largest
B, ρ, σ
number of trees, correlation between their predictions, and one tree’s spread; averaging only removes the (1 − ρ) part

The common mistake

Choosing a model by its score on its own training rows

A deep tree can score an AUC of 0.95 on the rows it was grown on and 0.68 on held-out folds, while a logistic regression scores 0.76 held out. Picking the tree because of its 0.95 picks the worse model: the 0.27 gap is noise it memorised. Compare models only on held-out scores, and shrink an overfitting tree’s depth or raise its minimum leaf size.

Remember

  • Cross-validation predicts every row once, from a model that never saw it. Compare models on those held-out scores.
  • Forests beat single trees by averaging trees made different by bootstrap samples and random columns. k-NN needs standardised columns.
  • Permutation importance shows what a model leans on; correlated columns share the credit.
