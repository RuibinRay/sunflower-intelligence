Data Cleaning and Preparation

Turn a messy export into data you can trust: profile it, fix records and formats, handle missing and unusual values, and prepare it for analysis without biasing the result.

Start with lesson 1 Take the diagnostic first

What you will learn

  • Describe a dataset precisely: its unit of observation, variables, types and keys.
  • Profile a dataset and write validation rules that catch invalid records.
  • Find and resolve duplicates, wrong data types, inconsistent dates and messy text.
  • Choose between deleting and imputing missing values, and explain the bias each can cause.
  • Detect outliers, decide whether they are errors, and treat skewed variables.
  • Scale, encode and reshape data for analysis without leaking information from test data.
  • Document every cleaning decision in a reproducible data quality report.

Prerequisites

  • B01 Introduction to Business Analytics — recommended

How it works

Each lesson teaches the idea from first principles, works examples step by step, lets you explore it in an interactive, then has you practise with feedback. A lesson is complete when you have worked its guided problems and scored 80% on its knowledge check. Mastery is tracked separately and comes back for review before you are likely to forget. Each module ends with a test; the course ends with a project and a final assessment.

Fictional case

Lantern Coffee Co. A fictional coffee business founded by Ana Lim. It starts as a catering and barista-training service, opens an online shop for beans, then launches a canned cold brew. Every name and figure in it is invented for teaching.

Modules and lessons

Module 1 Understanding your data

  1. 1Datasets: rows, columns, records and variablesBefore you clean or analyse a table, describe it exactly: what one row is, what kind of value each column holds, which column identifies each row, and what every column is supposed to contain. Get this wrong and correct arithmetic gives the wrong answer.75 min · not started
  2. 2Profiling a dataset and writing validation rulesFind out what a dataset really contains before you change it: profile every column, name each problem by the quality dimension it affects, and turn what you find into precise validation rules and a cleaning plan.75 min · not started
  3. ✓Module 1 test10 questions on this module. 70% passes.not taken

Module 2 Fixing records and formats

  1. 3Duplicate recordsA record counted twice inflates revenue, customer numbers and averages without any warning. Learn to tell exact copies, conflicting versions and near duplicates apart, decide what counts as “the same” for the business, and remove duplicates without deleting genuine repeat orders.80 min · not started
  2. 4Incorrect data types and inconsistent datesA price stored as text won’t add up, and a date stored as text won’t sort. Learn to give every column the right data type, convert numbers written in different local formats, keep identifiers as text, and turn a column of mixed dates into unambiguous ISO 8601 dates without guessing.75 min · not started
  3. 5Text cleaning and consistent categories“North”, “north ”, “N.” and “Nrth” are one region to a person and four to a computer. Learn to normalise whitespace, case and Unicode, consolidate variants with a reviewed mapping table, split and extract fields with simple patterns, and see how consolidation changes counts and averages.70 min · not started
  4. ✓Module 2 test12 questions on this module. 70% passes.not taken

Module 3 Missing and unusual values

  1. 6Missing valuesA blank cell is a question: why is the value missing? Learn to find every form missing data takes, judge whether the gaps are random, and choose between deleting and imputing without quietly biasing the answer.75 min · not started
  2. 7Outliers and impossible valuesSome unusual values are mistakes, some are impossible and some are the most important rows in the file. Learn to flag them with quartile fences and robust z-scores, to see why the ordinary z-score can miss them, and to choose and document a treatment that fits the question.90 min · not started
  3. 8Skewed data and transformationsOrder values, hotel bills and study hours pile up at the low end and stretch out in a long tail. Learn to measure that skew, to see when it distorts summaries, outlier rules and models, and to transform a variable, read the results back in real units, and know when to leave it alone.75 min · not started
  4. ✓Module 3 test12 questions on this module. 70% passes.not taken

Module 4 Preparing data for analysis

  1. 9Normalisation and standardisationPut numeric variables on comparable scales with min–max normalisation, standardisation and robust scaling, so that no variable dominates an analysis just because of its units. Learn which methods need scaling, what an outlier does to each scaler, and how to fit the scaling on training data only so that no test information leaks into the model.105 min · not started
  2. 10Encoding categorical variablesTurn categories such as region, room type or roast into numbers a model can use, without inventing an order or a distance the categories don’t have. Learn one-hot and dummy coding, ordinal, frequency and target encoding, and how to handle the dummy-variable trap, rare and unseen categories, and variables with thousands of values.90 min · not started
  3. 11Transforming and reshaping dataClean data rarely arrives in the shape a question needs. Learn to derive new variables, sort values into bins, aggregate, reshape between wide and long, and join tables, and to check every step so that it adds information rather than errors.105 min · not started
  4. 12Data quality reporting and a reproducible workflowCleaning is finished only when someone else can see what you did, why, and what it means for the results, and can repeat it. Learn to write a data quality report, keep a cleaning log, and run a reproducible workflow from the raw export to analysis-ready data.70 min · not started
  5. ✓Module 4 test12 questions on this module. 70% passes.not taken
