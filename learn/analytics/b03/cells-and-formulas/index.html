Cells, references and formulas

A spreadsheet is only as trustworthy as its formulas. Learn how Excel reads a formula, how references move when a formula is filled or copied, why a number can look rounded without being rounded, what each error value means, and how to lay out a worksheet that someone else can check.

About 70 minutes

Before you start

You will be able to

  • Identify cells, ranges and references in a worksheet, and distinguish a typed value from a formula.
  • Calculate what a formula returns using Excel’s order of operations, including negation and the percent sign.
  • Build formulas with relative, absolute and mixed references that stay right when filled down and across.
  • Explain the difference between a cell’s displayed value and its stored value, and decide when to round with ROUND.
  • Diagnose the common error values and trace a formula’s precedents and dependents.
  • Design a worksheet whose inputs are labelled and kept apart from its calculations, so that it can be checked.

Review first

  • Incorrect data types and inconsistent dates — Numbers stored as text and serial dates behave differently in formulas; this lesson assumes you can recognise them.
  • Summarising data: changes, averages and spread — Totals, averages and shares of a total are what the formulas here calculate.
  • Arithmetic with percentages: a 6% rise on $14.00 is 14 × 1.06 = $14.84.

Fictional case A fictional coffee business founded by Ana Lim. It starts as a catering and barista-training service, opens its own cafés and an online shop for beans, and plans a canned cold brew.

The idea

Fictional case

Ana Lim has B02’s cleaned export of Lantern’s spring orders: 231 orders placed between 1 March and 30 June 2026, worth $9,096.15 in all. Before she builds anything on it she wants two things. First, every order’s value rebuilt from its parts (quantity times unit price, less any discount) and compared with the order_total the shop recorded. Second, a quick look at what a price rise in July would have done to those orders. Both are jobs for formulas: a few typed once, then filled down hundreds of rows.

The grid

An Excel file is a workbook, and each tab in it is a worksheet: a grid of columns lettered A, B, C … and rows numbered 1, 2, 3 …. Where a column and a row cross is a cell, and its address, the column letter followed by the row number, is its cell reference: F2 is the cell in column F, row 2. After Z the column letters double (AA, AB …) and then triple. Microsoft’s published limit is 1,048,576 rows by 16,384 columns per worksheet, so the last column is XFD. Lantern’s orders fill a sliver of that.

A cell range is a rectangle of cells, written as its top-left and bottom-right cells joined by a colon: B2:B232 is column B from row 2 to row 232, and B2:D9 is three columns by eight rows, 24 cells. A whole column is written with its letter twice, F:F. Microsoft calls the colon the range operator. A comma joins references into one list, as in =SUM(B2:B9,D2:D9), and a single space gives only the cells two references share, so =SUM(B7:D7 C6:C8) adds C7 alone; you will rarely need that one.

Values and formulas

A cell holds either a value or a formula. A value is what you type: a number (14), text (House Blend 250g), a date, which Excel stores as a serial date, or one of the logical values TRUE and FALSE. A formula starts with an equals sign and calculates. Type =G2*H2-I2 into a cell and the cell shows the result while the formula bar above the grid shows the formula. When G2, H2 or I2 changes, the result changes with it: that is the point of a spreadsheet, and it works only if the formula refers to the cells that hold the inputs.

In Lantern’s order sheet, column G holds quantity, H unit_price and I discount. The first order, LC-10001, was 2 Gift Box Trios at $58.00 with a $5.00 promotion code, so =G2*H2-I2 returns 2×58−5=1112 \times 58 - 5 = 1112×58−5=111, the $111.00 the shop recorded.

A number typed inside a formula, such as the 0.1 in =G2*H2*0.1, is a constant. It is invisible in the grid, it doesn’t change when the inputs do, and whoever revises the sheet next year has to find every copy of it. Most of the advice on worksheet design at the end of this lesson follows from that.

How Excel reads a formula

A formula combines references, constants, functions (the next lesson) and operators. The arithmetic operators are + (add), - (subtract, or negate a single number), * (multiply), / (divide), ^ (raise to a power) and % (percent). The comparison operators return TRUE or FALSE, and & joins text. When a formula has several operators, Excel doesn’t work strictly from left to right. It follows an order of precedence, which Microsoft publishes:

Excel’s order of operations, first to last (Microsoft)
OrderOperatorMeaning
1: (colon), a single space, , (comma)Reference operators: range, intersection, union
2-Negation, as in −1
3%Percent
4^Exponentiation
5* and /Multiplication and division
6+ and -Addition and subtraction
7&Joining two pieces of text
8= < > <= >= <>Comparison

Operators on the same level are worked from left to right, so =20/4*2 is 10, not 2.5, and =2^3^2 is (23)2=64(2^3)^2 = 64(23)2=64, where a mathematician would read 232=5122^{3^2} = 512232=512. Parentheses override everything. Microsoft’s own example is =5+2*3, which gives 11, against =(5+2)*3, which gives 21.

Two rows of the table surprise people. Negation comes before exponentiation, so =-2^2 squares −2 and returns 4; write =-(2^2) or =0-2^2 if you mean −4. Percent divides only the number it follows by 100, before any multiplying or adding, so =5+10% is 5.1, not 5.5. In Lantern’s line total, multiplication comes before subtraction, so =G2*H2-I2 takes the discount off the order once. =G2*(H2-I2) would take it off every bag, and turn LC-10001’s $111.00 into 2×(58−5)=1062 \times (58 - 5) = 1062×(58−5)=106.

Excel also converts values when an operator needs another type. Microsoft’s examples: ="1"+"2" returns 3, because text that looks like a number is converted, and =1+"$4.00" returns 5; but =SQRT("8+1") returns #VALUE!, because “8+1” isn’t a number in any format Excel accepts. Relying on these conversions is fragile, and B02’s rule still applies: convert deliberately and check.

Key idea: Read a formula aloud before you trust it

Say what each part does in words: “quantity times unit price, then minus the discount”. If the words don’t match the formula, add parentheses until they do. Parentheses that change nothing still make a formula easier to check.

In depth

Relative, absolute and mixed references

When a formula is filled or copied to another cell, Excel adjusts its references. By default a reference is a relative reference: it means “the cell so many rows and columns away from this one”. The formula =G2*H2-I2 in K2 really says “this row’s quantity times this row’s price, less this row’s discount”, so filled down to K3 it becomes =G3*H3-I3, and so on to row 232. That is exactly right for a calculation repeated on every row.

It is exactly wrong for an input that every row shares. Suppose P1 holds a planned price rise of 6% and L2 holds =H2*(1+P1). Filled down, L3 becomes =H3*(1+P2); P2 is empty, an empty cell counts as 0 in arithmetic, and every row after the first quietly shows today’s price.

A dollar sign fixes the part of a reference it stands in front of. An absolute reference fixes both, $P$1, and =H2*(1+$P$1) fills down correctly. A mixed reference fixes one part: $P1 keeps the column, P$1 keeps the row.

A reference in a formula copied two rows down and two columns to the right (Microsoft’s example)
ReferenceBecomesType
$A$1$A$1Absolute: nothing moves
A$1C$1Mixed: the column moves, the row stays
$A1$A3Mixed: the row moves, the column stays
A1C3Relative: both move

You don’t have to type the dollar signs. In Windows Excel, put the cursor in a reference in the formula bar and press F4 to cycle through the combinations of absolute and relative; on a Mac, press Command+T (Microsoft’s Mac page). The question to ask of every reference is: when this formula is copied, which part of this address should move?

Mixed references earn their keep in two-way tables. To show four products’ prices after rises of 4%, 6% and 10%, put the prices down column B (B3:B6) and the rises across row 2 (C2:E2). Every cell needs “this row’s price, in column B” and “this column’s rise, in row 2”, so the formula in C3 is =$B3*(1+C$2). Filled across and down it fills all twelve cells correctly; the challenging example works it through.

Filling, copying and moving

The fill handle is the small square at the bottom-right corner of the selected cell: drag it down or across and Excel copies the formula into each cell it passes, adjusting relative references as it goes. Ctrl+D fills the top cell of a selection down, and Ctrl+R fills the left-hand cell right; on a Mac, Control+D and Control+R do the same (Microsoft’s Mac page). Copying and pasting adjusts references in the same way. Moving a formula, by cutting and pasting it or dragging its cell, does not: Microsoft notes that the references stay the same whatever their type.

A column of calculations should hold one formula, filled. Show Formulas (below) makes this easy to check, because every cell in the column should then read the same apart from its row numbers. A cell that differs, such as a typed-in number among formulas or a formula pointing at the wrong row, is a common sign of a spreadsheet error, and the applied example finds one.

Ranges and whole-column references

Functions work on ranges: =SUM(J2:J232) adds the 231 order totals. If Ana pastes July’s orders below row 232, that range doesn’t grow; a whole-column reference such as =SUM(J:J) does, and SUM skips the text heading in J1.

But a whole column includes everything in it. Put that total in J234 and the formula refers to its own cell, a circular reference. Microsoft also advises against whole columns in heavy functions such as SUMPRODUCT, which then multiply every cell in the column, empty ones included. Excel tables, whose references grow with the data, are the better answer; they come in the tables-and-cleaning lesson.

What a cell shows and what it stores

A number format changes how a value looks, not the value. Format 2.345 to two decimal places and the cell shows 2.35, but every formula that uses it still gets 2.345. Usually that is what you want: carry full precision and round only what you report.

It goes wrong when the rounded figure is the real one. Split a $100 platter fee into three invoice lines with =100/3: each line shows $33.33, the total =SUM(B2:B4) shows $100.00, and a client who adds the lines gets $99.99. If each line is what is actually charged, round it. =ROUND(100/3,2) stores 33.33, and then the lines and the total agree, at $99.99; whether the missing cent goes on one line is a business decision, not a formatting one.

Underneath, Excel stores numbers in binary to 15 significant digits of precision. Most decimal fractions, 0.1 among them, have no exact binary form, so tiny errors appear far to the right of the decimal point. Microsoft’s example: =(43.1-43.2)+1, formatted to 15 decimal places, shows 0.899999999999999 rather than 0.9. Since Excel 97, when an addition or subtraction gives a result at or very close to zero, Excel compensates for the conversion error, so Microsoft’s =1.333+1.225-1.333-1.225 shows 0 where Excel 95 showed −2.22044604925031E−16.

You may also meet =0.1+0.2=0.3. In binary, 0.1 + 0.2 is not exactly 0.3, yet Excel shows TRUE, and so do the worksheets on this site, which compare numbers to 15 significant digits. Microsoft doesn’t document the exact rule its comparisons follow, so don’t build a model on the exact equality of calculated decimals: compare rounded values, =ROUND(A2,2)=ROUND(B2,2), or test the size of the difference, =ABS(A2-B2)<0.005. Microsoft also offers a workbook option, Set precision as displayed, which permanently cuts every stored value down to its displayed format. It can’t be undone; leave it alone.

Error values

When a formula can’t produce a result it returns an error value, which names what went wrong. Learn to read them rather than hide them.

Tracing a formula

Three tools on the Formulas tab show how a sheet is wired. Show Formulas switches every cell between its result and its formula (Ctrl+`, the grave-accent key, in Windows; Control+` on a Mac, as Microsoft’s keyboard shortcuts page lists), which is the fastest way to spot the odd formula out in a column. Trace Precedents and Trace Dependents, in the Formula Auditing group, draw arrows from the cells a formula uses (its precedents) and to the formulas that use a cell (its dependents). The arrows are blue for cells without errors and red for cells that cause errors, and Remove Arrows clears them.

Evaluate Formula, in the same group, works through one cell’s formula a step at a time. Microsoft’s example is =IF(AVERAGE(F2:F5)>50,SUM(G2:G5),0) with 55, 35, 45 and 25 in F2:F5. The first step replaces the average with 40; the next turns 40>50 into FALSE; and the formula returns 0 without ever calculating the SUM. Stepping through like this shows exactly where a long formula stops doing what you meant.

A circular reference is a formula that refers to its own cell, directly or through other formulas. Excel warns the first time one appears, and the cell may then show 0 or its last calculated value; Formulas > Error Checking > Circular References, and the status bar, show where it is. It is almost always a mistake, such as a total inside the range it adds. Excel can be told to allow it (File > Options > Formulas > Enable iterative calculation, after which it recalculates up to 100 times by default, or until values change by less than 0.001), but a model that needs that should say so in large letters.

Designing a worksheet someone else can check

  • Keep inputs apart and labelled. Every assumption (the price rise, the subscription discount, a fee rate) goes in its own cell, with a label, a unit and a source, such as “Price rise from 1 July, % of current price (Ana’s plan)”.
  • Don’t hard-code numbers in formulas. Refer to the input cell with an absolute reference or a name. Constants that can never change, such as 12 months in a year, are the exception.
  • One formula per column, filled. Consistent formulas can be checked by checking one of them.
  • Separate data, calculations and results. The raw data stays untouched, as B02 insisted; calculations come next and results last, so a reader can follow the flow.
  • Build in checks. A cell that should show zero when the sheet is right, such as the rebuilt line totals minus the recorded order totals, catches errors you weren’t looking for.
  • Name the key inputs, so that formulas read like the business rule.

A defined name labels a cell or range so that formulas can use the label. Select P1, type Rise in the Name Box to the left of the formula bar and press Enter, and =H2*(1+Rise) reads like the rule it implements. Formulas > Name Manager lists, edits and deletes names, and Formulas > Create from Selection names cells from the labels beside them. According to Microsoft’s Name Manager page, a name can be up to 255 characters long and applies to the whole workbook unless you choose otherwise. When you define a name by selecting cells, Excel stores an absolute reference such as Sheet1!$P$1, so the name doesn’t move when a formula is filled.

Why it matters: spreadsheet errors are normal

Spreadsheet errors are not rare accidents. Raymond Panko’s review of the research reported that the field audits from 1997 onward found errors in at least 86% of the spreadsheets audited, and that across development experiments 51% of the spreadsheets participants built contained errors. People don’t see their own: in one experiment the developers’ median estimate of the chance that their spreadsheet held an error was 10%, yet 86% of them had made one. The only technique Panko found demonstrated to work was code inspection, a group checking a spreadsheet cell by cell, and he notes that even this catches only about 80% of errors.

The best-known case is economic. In 2010 Carmen Reinhart and Kenneth Rogoff reported that countries with public debt above 90% of GDP grew more slowly. Replicating their work in 2013, Thomas Herndon, Michael Ash and Robert Pollin found that the working spreadsheet averaged rows 30 to 44 instead of rows 30 to 49, which left Australia, Austria, Belgium, Canada and Denmark out of the calculation. With that error, and with data the paper had excluded and an unusual weighting corrected as well, average growth for the high-debt countries went from the published −0.1% to 2.2%. A range that stopped five rows short became part of a policy debate.

Common mistakes

  • “Copying a formula copies the same calculation.”

    Copying copies the pattern, not the cells. Relative references move with the copy, which is right for row-by-row data and wrong for a shared input. Before you fill, ask of every reference which part should move, and put a $ in front of the part that shouldn’t.

  • “=-2^2 is −4.”

    In Excel, negation comes before exponentiation, so =-2^2 squares −2 and returns 4. Write =-(2^2) when you mean −4. Similarly, % applies only to the number it follows: =5+10% is 5.1.

  • “If it shows 2 decimals, it is rounded.”

    A number format changes the display, not the stored value, and formulas use the stored value. When the rounded figure is what is charged or paid, round it with =ROUND(…,2); otherwise keep full precision and format the result.

  • “Typing the number into the formula is fine if it is right today.”

    A constant inside a formula is invisible, won’t change when the input does, and has to be found and edited in every copy. Put each assumption in a labelled input cell and refer to it, absolutely or by name.

  • “A total at the bottom can use the whole column.”

    =SUM(F:F) placed in column F includes its own cell, which makes a circular reference. Put the total outside the column it adds, or refer to the exact range (or, later in this course, to an Excel table column).

  • “If the formula returns a number, it is right.”

    Most spreadsheet errors return plausible numbers, and their authors are confident they have none. Check against a total calculated another way, look at the formulas (Show Formulas) for the odd one out, and have someone else inspect the important cells.

In practice

Ana’s order workbook. Ana lays out the workbook in the order a reader needs. The first sheet holds the cleaned orders exactly as B02 delivered them; nothing is typed over. An inputs block holds the planned price rise and the subscription discount, each in its own labelled cell with its unit, its source and the date she set it, and each with a name. The calculation columns (line total, value at new prices) each hold one formula filled down.

A checks block at the top shows the rebuilt line totals minus the recorded totals, which must be 0.00, and the number of order rows, which must be 231. When she sends the workbook to Lantern’s accountant, the first thing he looks at is the checks block.

Before she trusts a result. When the price-rise sheet says a 6% rise would have added $25.38 to the first ten orders, Ana checks it two ways: by the formula column and by the quick estimate, gross value times 0.06. She also tests the sheet with an input whose answer she knows. Set the rise to 0% and every new price must equal the old price; set it to 100% and every price must double. A formula that passes both tests and agrees with an independent estimate is not proof of correctness, but a formula that fails either one is certainly wrong.

Fictional case

Riverbend Cycles, a fictional bike-repair shop, prices its services from a sheet in which a mechanic’s hourly rate sits in one named input cell, Rate, and every service price is hours × Rate + parts. When the owner raised the rate from $45 to $48 an hour, she changed one cell, and 30 service prices updated. Her previous price list, inherited from the shop’s former owner, had the rate typed into each formula; the year she changed it by hand, two services kept the old rate for six months before a customer queried a bill.

Reviewing someone else’s sheet. Analysts who check spreadsheets for a living follow a routine much like Ana’s. Turn on Show Formulas and scan each column for the odd formula out. Trace the precedents of each key result back to its inputs. Look for constants inside formulas and for totals that add ranges ending short of the data, the Reinhart–Rogoff error.

Then recalculate one or two results by hand. Panko’s research suggests that the author is the person least likely to find the errors, which is why the review is done by someone else.

Summary

  • A cell holds a value or a formula; a formula starts with = and recalculates when the cells it refers to change. Keep numbers that can change out of formulas.
  • Excel’s order of operations puts negation before ^ and % before * and /: =-2^2 is 4 and =5+10% is 5.1. Use parentheses to say what you mean.
  • Relative references move when a formula is filled or copied; $A$1 fixes both parts, $A1 the column and A$1 the row. F4 (Command+T on a Mac) cycles through them. Two-way tables need mixed references.
  • A number format changes only the display; Excel stores 15 significant digits. Round with ROUND when the rounded value is the real one, and don’t test calculated decimals for exact equality.
  • Error values name the problem: #DIV/0!, #VALUE!, #NAME?, #REF!, #N/A and #NUM!. Show Formulas, Trace Precedents and Dependents, and Evaluate Formula show how a sheet is wired; a circular reference is almost always a mistake.
  • Design for checking: labelled inputs, one formula per column, separate data, calculations and results, named key inputs, and check cells that should show zero.
  • Spreadsheet errors are normal and their authors rarely see them; an independent check is part of the work, not an insult.

Terms introduced

Cell reference
The address of a cell, its column letter followed by its row number (such as F2), used in a formula to read that cell’s value.
Cell range
A rectangle of cells written as its top-left and bottom-right cells joined by a colon, such as B2:D9; a whole column is written F:F.
Formula
An entry in a spreadsheet cell that begins with an equals sign and calculates a result from values, references, operators and functions.
Relative reference
A cell reference without dollar signs, such as A1, which Excel adjusts when the formula is filled or copied, so that it keeps the same position relative to the formula’s cell.
Absolute reference
A cell reference with a dollar sign before both its column and its row, such as $A$1, which stays the same when the formula is filled or copied.
Mixed reference
A cell reference that fixes either its column ($A1) or its row (A$1), so that only the other part moves when the formula is filled or copied.
Error value
A result such as #DIV/0!, #VALUE!, #NAME?, #REF!, #N/A or #NUM! that Excel shows when a formula can’t calculate, naming the kind of problem.
Circular reference
A formula that refers to its own cell, directly or through other formulas.
Defined name
A name given to a cell, range or value, such as Rise for the cell holding a price rise, that formulas can use instead of the reference.
