Pixel Arcade

New to code? Start with Data Diner, or with Cell Craft if you would rather not code yet. Each of the eight learning games opens by saying what the language is, teaches one idea per level, runs your real code, and ends the level with what you just learned and a quick check. The two endless games keep it fresh with questions made new each run.

Learn by playing

One idea per level, explained first and checked after. Your code is really run.

  • Python · start hereData DinerNever written code? Start here. Run the till with a few lines of Python: print, variables, text and numbers, lists, loops, dictionaries and your own functions.12 levels
  • PythonPy QuestSteer a bee round the garden by writing real Python: function calls, loops, variables, if and while, and your own functions.10 levels
  • Python · pandasTable TamerLoad a file of orders with pandas and question it: pick columns, filter rows, add a column, sort, count, group, fill the gaps and merge two tables.12 levels
  • SQLQuery QuestAnswer the coffee shop’s questions with SQL, from SELECT and WHERE to GROUP BY and JOIN. The rows your query keeps light up on the shelf.17 levels
  • SpreadsheetsCell CraftLearn spreadsheet formulas on a live sheet, with no code: cell references, filling down, SUM and AVERAGE, $ to pin a cell, IF, COUNTIF, SUMIF and VLOOKUP.12 levels
  • HTMLTag BuilderBuild the shop’s web page tag by tag and watch it appear as you type: headings, links, images, lists and page landmarks.8 levels
  • CSSStyle ShopDress the shop’s page with CSS: rules, classes and ids, the box model, which rule wins, and laying things out in a row.9 levels
  • JavaScriptScript LabWrite real JavaScript and run it: variables, template strings, if, arrays, loops, functions, objects, map and filter, then change a page and react to a click.12 levels

Endless games

New questions every run. Beat your best score.

  • Python · SQL · HTML & CSSBug BattleAn endless quiz fight. Read the code, pick what it does, sting the bug. New questions every run, a daily run, and practice on your weak spots.Endless
  • Python · SQL · HTML · CSSSyntax CatcherWords fall, the rule changes every round. Catch the real keywords, tags and properties and let the fakes drop.Endless

Badges

    Your XP, stars and scores are kept in this browser only. Nothing is sent anywhere.

    The arcade goes with the Business Analytics school. Its games use Lantern Coffee, the fictional shop from the courses, and every table and order in them is made up. The small Python, pandas, SQL and CSS readers that run here cover the parts the levels teach; they are not the full languages. Cell Craft uses the same spreadsheet engine as the Excel lessons, and Script Lab runs your JavaScript for real, in a separate thread that cannot touch the page.
