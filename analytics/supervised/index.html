Supervised learning learns from rows where the answer is known, then predicts it for rows where it isn’t. Four models answer the same question here, and every one is judged only on rows it never trained on.

Your data

Choose a table, then the yes-or-no column to predict (any column with exactly two values) and the columns to predict it from. Every section below uses this choice. A table you loaded under Explore appears here too.

Predictors

Compare models

Logistic regression, a decision tree, nearest neighbours and a random forest, scored the same fair way: the rows are dealt into five folds that keep the yes/no balance, and each model is trained on four folds and scored on the fifth, five times over. Every row ends up predicted by a model that never saw it.

    A tree you can read

    A decision tree asks one yes-or-no question at a time, choosing at each step the split that leaves the two sides purest (lowest Gini impurity). A shallow tree is a set of rules a person can check; a deep one fits the training rows better and new rows worse.

    These settings also drive the decision tree in Compare models above.

      Feature importance

      Which columns does a model lean on? Permutation importance shuffles one column among the held-out rows, breaking its link to the outcome, and measures how far the AUC falls. It works the same way for every model, so the answers are comparable.

      • Two columns that carry the same information share the credit: shuffle one and the model leans on the other, so both can look minor.
      • A small negative value means the column didn’t help; shuffling it changed the score by chance.
      • Importance says what this model uses to predict, not what causes the outcome.

      Logistic regression in depth

      Logistic regression is the model you can explain line by line: each coefficient becomes an odds ratio with a confidence interval. Fitted on every row for the reading, and judged on the 30% of rows held back from a separate fit.

      —area under the ROC curve, on the 30% of rows held back
